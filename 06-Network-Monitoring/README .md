
# Network Monitoring Lab

## Objective
Learn how to monitor network interfaces, connections, and routing information in Linux.

## Commands Used
```
# bash
ip a
nmcli device show
ss -a
ss -tulpn
netstat -nr
ping 192.168.1.1 -c 5
```
## Results
- Displayed network interfaces
- Reviewed IP addressing information
- Identified active connections
- Inspected listening ports
- Verified network connectivity

## Skills Learned
- Network Monitoring
- Routing Analysis
- Port Inspection
- Connectivity Testing


## Lessons Learned
- Learned how to inspect network interfaces and IP addresses.
- Learned how to view active network connections.
- Learned how to identify listening ports and services.
- Learned how to analyze routing information.
- Learned how to verify network connectivity using ping.
