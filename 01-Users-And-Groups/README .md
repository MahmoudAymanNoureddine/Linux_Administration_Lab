
# Users and Groups Lab

## Objective
Learn how to create and manage users and groups in Linux.


## Commands Used
```
# bash
useradd analyst1
useradd analyst2
passwd analyst1
passwd analyst2
groupadd soc_team
usermod -aG soc_team analyst1
usermod -aG soc_team analyst2
id analyst1
id analyst2
```


## Results
- Created two users
- Created a group
- Added users to the group
- Verified memberships

## Skills Learned
- User Management
- Group Management
- Access Control Basics

## Lessons Learned
- Learned how to create local users in Linux.
- Learned how to create and manage groups.
- Learned how to assign users to groups.
- Learned how to verify user and group memberships.
