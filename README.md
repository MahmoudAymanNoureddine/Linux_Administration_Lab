# Linux Administration Lab

## Overview
This repository contains practical Linux Administration labs completed after studying Red Hat System Administration I and II.

## Topics Covered
- User and Group Management
- Access Control Lists (ACL)
- Cron Jobs
- Service Management
- SSH Monitoring
- Network Monitoring
- Firewalld
- SELinux
- Logical Volume Management (LVM)
- Network File System (NFS)

## Environment
- Red Hat Enterprise Linux
- VMware Workstation
- Kali Linux
